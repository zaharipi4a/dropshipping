# Knowledge Base

Reusable facts across **all** products. Product folders hold *decisions about one
product*; this folder holds *facts about the world* (suppliers, competitors,
communities, creators, hooks) so no agent researches the same thing twice.

- Written by the `librarian` after every stage (in the background), deduplicated.
- Read by every agent before researching. Check here first, then search the web.
- Each table row has `Source` (stage file) and `Date`. Data labels (`measured`, `estimated`, `assumed`) are kept as-is.
- Performance columns (CTR, hold rate, CVR) are filled in by `performance-analyst` results, which turns this into a library of what actually works.

| File | Contents |
|---|---|
| `products.md` | Every product evaluated, with proof signals and verdict |
| `suppliers.md` | Supplier directory: costs, shipping, reliability |
| `competitors.md` | Competitor stores, brands and ads |
| `communities.md` | Where each segment lives online |
| `creators.md` | Creators/influencers to seed or hire |
| `hooks-angles.md` | Hooks and angles, with measured performance when available |
| `sources.md` | Data sources and tools: what works, what needs a login |
